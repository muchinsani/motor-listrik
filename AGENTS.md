# Kebijakan Review

- Baca docs/review/review-comment-format.md dan gunakan formatnya untuk Review Summary serta komentar inline.
- Gunakan dokumen review sebagai sumber aturan proyek yang ada di docs/review/.
- Setiap temuan harus memiliki bukti dari kode.
- Cantumkan referensi dokumen jika temuan terkait requirement.
- Laporkan konflik atau ketidakjelasan dokumen; jangan mengarang aturan.
- Pisahkan defect, saran nonblocking, dan kekurangan pengujian.
- Komentar code review mengikuti format Issues, Recommendation dan Document References
